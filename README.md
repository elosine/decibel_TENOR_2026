# decibel_TENOR_2026

A piece for the Decibel ensemble — bass flute, bass clarinet, viola, cello, percussion and electronics (the
instrumentation is not final) — with live electronics, as an animated scrolling score.
Piece #7 in the composer's custom-composition-system lineage; copied forward from `septet_LGMF_2026` (the copy is not made
yet — this repo holds the working documents only). The live electronics come from the shared engine,
`live-electronics-system`.
